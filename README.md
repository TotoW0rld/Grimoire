# Grimoire — le dernier archimage

Roguelike d'action en pixel art, dans un univers médiéval : tu joues un archimage contre des hordes de gobelins
et d'ogres, avec des pluies de coffres et de cartes, des sorts à cercles magiques et des cinématiques.
Le boss de la Plaine : **Vhal, l'Ancien Cerf**.

*Version bêta.*

## Télécharger

👉 **[Dernière version](../../releases/latest)**

- **Windows** : `Grimoire-Windows.zip` — dézippe, puis double-clic sur `Grimoire.exe`.
  Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même »
  (le jeu n'est pas signé, c'est normal pour une bêta).
- **Linux** : `Grimoire-Linux.zip` — dézippe, puis lance `Grimoire.x86_64` (au besoin : `chmod +x Grimoire.x86_64`).

Rien à installer.

## Mises à jour

Inutile de revenir ici : quand une nouvelle version sort, le jeu l'annonce sur l'écran titre
(« Mise à jour disponible »). Un clic, il télécharge seulement le nouveau contenu et redémarre tout seul.
**Ta sauvegarde est conservée** : elle est rangée à part, pas dans le dossier du jeu
(`%APPDATA%\Godot\app_userdata\Grimoire` sous Windows, `~/.local/share/godot/app_userdata/Grimoire` sous Linux).

| Touche | Action |
|---|---|
| ZQSD / flèches | se déplacer |

| Maj | ruée |
| Espace | transfert |
| R | grand sort |
| Échap | pause |
